# ecommerce-sales-analysis
A beginner-friendly eCommerce Sales Analysis project using Python, Pandas, NumPy, and Matplotlib. This project analyses sales data, calculates revenue, identifies best-selling products, compares regional performance, and visualizes product sales through bar charts.

eCommerce Sales Analysis Using Python

Project Overview

This beginner-level project analyses eCommerce product sales using Python.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

Key Analysis

- Calculate total sales revenue.
- Calculate average revenue per record.
- Identify the best-selling product.
- Analyse product and regional sales.
- Visualise product sales using a bar chart.

Files

- "ecommerce_analysis.py" – Python source code
- "ecommerce_sales.csv" – Sales dataset
- "ecommerce_chart.png" – Sales chart

How to Run

Install the required libraries:

"pip install pandas numpy matplotlib"

Run the script:

"python ecommerce_analysis.py"

Learning Outcomes

Practised data manipulation, aggregation, numerical calculations, and data visualization using Python.
